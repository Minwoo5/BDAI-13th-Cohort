# BDAI 13th Cohort

This repository contains my study notes and implementation exercises from the
BDAI (Big Data Analysis) 13th Cohort.

## Curriculum

### 1. Machine Learning Modeling (ML1)

A 16-week course covering the end-to-end machine learning workflow, from data
preprocessing to model evaluation and management.

Topics include:

- Machine Learning fundamentals
- Data preprocessing
- Regression
- Classification
- Ensemble methods
- Cross-validation
- Hyperparameter tuning
- Regularization
- Imbalanced data handling
- Unsupervised learning
- MLflow-based model management
- Introduction to recommender models

### 2. Recommender System Implementation

A practical course focused on designing and implementing recommender systems
using real-world financial product data.

Topics include:

- Recommender System fundamentals
- Popularity / Rule-based Recommendation
- Content-Based Filtering
- Collaborative Filtering
- Matrix Factorization
- Machine Learning-based Recommendation
- Deep Learning-based Recommendation
